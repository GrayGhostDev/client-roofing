## Current Brand Positioning

### Core Identity

| Element | Current Position |
|---------|------------------|
| **Category** | Fast-casual Mediterranean |
| **Price Point** | Mid-range ($12-18 average ticket) |
| **Service Model** | Counter service with customization |
| **Key Differentiator** | 100% Halal + Build-your-own |
| **Target Experience** | Fresh, fast, personalized |

### Positioning Statement

**My Big Fat Shawarma** is a fast-casual Mediterranean restaurant serving health-conscious diners in West Bloomfield who want authentic, halal-certified, customizable meals. Unlike generic fast-casual chains, we offer true Mediterranean flavors with 100% halal certification and complete meal customization.
