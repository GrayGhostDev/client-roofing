## Daily Tasks (10-15 minutes)

### Morning Check (Before 10 AM)

#### Reviews
- [ ] **Google Reviews** - Check for new reviews
  - Respond to all reviews within 24 hours
  - Screenshot negative reviews for team discussion
  - Note: [Current Rating: _____ | Review Count: _____]

- [ ] **Yelp Reviews** - Check for new reviews
  - Respond professionally to all
  - Note: [Current Rating: _____ | Review Count: _____]

#### Social Media
- [ ] **Instagram** - Check notifications
  - Respond to comments (within 2 hours)
  - Reply to DMs
  - Repost any customer tags to Stories

- [ ] **Facebook** - Check notifications
  - Respond to comments and messages
  - Check for tags and mentions

#### Delivery Platforms
- [ ] **DoorDash** - Check ratings and feedback
- [ ] **Uber Eats** - Check ratings and feedback
- [ ] **Grubhub** - Check ratings and feedback

#### GBP Post (15 min)

- [ ] Mark as posted in queue document

- [ ] Prepare 1-2 Reels concepts

### Wednesday: Engagement Focus

#### Community Engagement (15 min)
- [ ] Check local Facebook groups for food questions
- [ ] Respond helpfully (not promotional)
- [ ] Check Nextdoor for relevant discussions
- [ ] Engage with local business posts

#### Influencer Monitoring
- [ ] Check if any influencers posted about us
- [ ] Save and repost any user-generated content
- [ ] Note potential micro-influencers in area

### Thursday: Outreach Day

#### Partnership Follow-up (15 min)
- [ ] Review partnership pipeline status
- [ ] Send follow-up emails to pending contacts
- [ ] Log any new responses
- [ ] Update Partner_Prospects.md with status

#### Review Generation
- [ ] Check if review request cards need restocking
- [ ] Remind staff about review request script
- [ ] Send follow-up to recent catering customers

### Friday: GBP and Prep

#### Second GBP Post (15 min)
- [ ] Post second weekly GBP update
- [ ] Add high-quality image
- [ ] Verify post is live

#### Weekend Prep
- [ ] Schedule weekend social content
- [ ] Prepare any weekend specials
- [ ] Ensure all platforms have current hours
