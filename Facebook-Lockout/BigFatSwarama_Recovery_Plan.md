## Step 1: Determine Lockout Type

**Check which applies:**

- [ ] **A) Password forgotten** - Can't log in to personal Facebook account
- [ ] **B) 2FA lockout** - Can log in but 2FA code not working
- [ ] **C) Personal account disabled** - "Account disabled" message
- [ ] **D) Business Page removed as admin** - Personal account works, but lost Page access
- [ ] **E) Business Manager access lost** - Can't access Business Suite/Manager
- [ ] **F) Account hacked** - Someone else changed credentials
- [ ] **G) Page unpublished/restricted** - Policy violation

## Step 2: Recovery Path Based on Lockout Type

### Path A: Password Recovery

1. Go to: https://www.facebook.com/login/identify
2. Enter the email or phone associated with the account
3. Select recovery method (email code, SMS code, or ID verification)
4. Follow prompts to reset password

### Path B: 2FA Recovery

1. On login screen, click "Having trouble?"
2. Options:
   - Use backup codes (if saved)
   - "Try another way" → ID verification
   - Use trusted contacts (if configured)
3. If no options work: https://www.facebook.com/help/contact/357439354283890

### Path C: Disabled Account Appeal

1. Go to: https://www.facebook.com/help/contact/260749603972907
2. Fill out appeal form:
   - Use email associated with disabled account
   - Explain situation clearly and professionally
   - Upload government ID if requested
3. Wait 1-30 days for response
4. Check email spam folder regularly

### Path D: Page Admin Access Lost

**If another admin exists:**
- Contact them to re-add you as admin

**If no other admin:**
1. Go to: https://www.facebook.com/help/contact/144aborar
2. Or: https://www.facebook.com/help/contact/180444840570444
3. Provide:
   - Proof you created the Page (emails, original setup info)
   - Business documentation showing ownership
   - Government ID matching Page info

### Path E: Business Manager Recovery

1. Go to: https://business.facebook.com/help
2. Click "Get Support" → "I can't access my account"
3. Submit business verification documents:
   - Business license
   - Tax ID documentation
   - Utility bill or bank statement with business name
4. If business was verified, reference verification ID

### Path F: Hacked Account

1. Go to: https://www.facebook.com/hacked
2. Click "My Account Is Compromised"
3. Enter email/phone for the account
4. Enter current OR previous password
5. Follow identity verification steps
6. Once recovered:
   - Change password immediately
   - Remove unknown devices
   - Enable 2FA
   - Review connected apps

### Path G: Page Unpublished/Policy Issue

1. Check email for policy violation notice
2. Go to: https://www.facebook.com/support
3. Or Account Quality: https://www.facebook.com/accountquality
4. Review specific violation
5. Submit appeal with explanation
